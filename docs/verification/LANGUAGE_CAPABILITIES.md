# Language capabilities

The client registers the capabilities actually advertised by each server. An advertised capability is not a completed integration test. Missing capabilities are not emulated with syntax highlighting.

| Language                  | Server                                                                               | Exercised evidence                                              | Advertised or implemented; still requires per-feature desktop acceptance                                                                                                                                                   |
| ------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JS / TS / JSX / TSX       | TypeScript Native; project TS < 7 uses typescript-language-server + project tsserver | TS Native type-error diagnostic through actual desktop IPC      | Completion, hover, signature, pull diagnostics, definitions/types/implementations, references, rename, actions, symbols, semantic tokens, hints, hierarchy; JS/JSX/TSX, cross-package and old TS project tests outstanding |
| HTML                      | Microsoft vscode-html-languageservice 5.6.2                                          | stdio initialize and `<di` completion containing div            | Hover, symbols, folding, selections, highlights, rename, links and formatting. This service does not provide a general HTML validator; no general HTML diagnostics claim                                                   |
| CSS / SCSS / Less         | Microsoft vscode-css-languageservice 6.3.10                                          | CSS unknown-property diagnostic and document symbols over stdio | Completion, hover, definitions/references, rename, actions, colors, links, highlights, formatting; SCSS/Less project tests outstanding                                                                                     |
| JSON / JSONC              | Microsoft vscode-json-languageservice 5.6.3                                          | JSON invalid syntax over stdio and actual desktop Monaco marker | Completion, hover, schema validation, symbols, folding, selections, links, colors, formatting. General code actions, references, definition and rename are not advertised                                                  |
| Rust                      | User/project rust-analyzer                                                           | Tool discovery only                                             | Standard rust-analyzer capability integration is wired; actual project and refactoring tests outstanding                                                                                                                   |
| Other detected text types | Lazy Monarch grammar + Monaco editing                                                | Grammar loader/type mapping                                     | Syntax/general editing only; no semantic language service claim                                                                                                                                                            |

Monaco formatting uses the Rust stdin formatter adapter with document-version checks; a separate range format request may currently be served by the language service instead of the configured external formatter. This gap remains open in the matrix.
