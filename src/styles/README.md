# 桌面样式约定

- 常规布局、尺寸、间距、排版和交互状态优先使用 Tailwind。颜色使用 `bg-editor`、`text-muted`、`border-panel` 等语义类，不使用默认调色板或任意颜色值。
- `theme.css` 是应用颜色的唯一来源，采用 VS Code Dark Modern。变量以 `--lc-` 开头，按用途命名；不同用途即使颜色相同也可以单独定义。新增颜色先补充语义变量，需要工具类时再在 `App.css` 的 `@theme inline` 中映射。
- Tailwind 间距基准为 `4px`，保证 13px 界面字体下的桌面控件密度。无法整除的既有尺寸可以使用明确的任意尺寸值。
- 复杂后代选择器、伪元素和动画使用就近的 CSS Modules，直接读取主题变量；不要通过大量 `@apply` 重建工具类。
- 命令、焦点判断和桌面验证使用的原始类名是行为钩子。需要保留这些后代选择器时，用模块根类约束 `:global(.hook)`，避免扩散到其他组件。
- Codicons 使用属性选择器定义字体。容器中覆盖图标尺寸时保留对应属性，保证第三方 CSS 与懒加载模块的先后顺序不改变尺寸。
- `integrations.css` 仅放第三方拥有节点的必要全局覆盖，并说明原因；共享滚动条 CSS 也会注入文件树 Shadow DOM。树宿主传递主题变量，内部样式不复制色值。
- `theme.css` 和 `startup.css` 提前从 HTML 加载；工作台仍延迟加载。Monaco、xterm 通过 `theme.ts` 一次读取并缓存实际颜色，适配器同时展开构建压缩产生的短十六进制值。终端设置解析保持无 DOM 依赖。
- 内联样式仅用于运行时位置、尺寸、虚拟列表偏移和媒体变换等动态数据。
